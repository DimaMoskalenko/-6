Програма для роботи зі словником успішності студентів

Опис
Це командний проєкт, у якому реалізовано програму для зберігання, обробки та виводу інформації про успішність студентів. Дані зберігаються у вигляді словника Python. Кожен учасник команди реалізував окрему функцію для роботи з цим словником.

Учасники команди
- Москаленко Дмитро — тімлід, створення словника, функція додавання студента
- Маслак Олександр — функція сортування студентів за середнім балом
- Красуля Ілля — функція пошуку студента за ПІБ
- Бречка Дмитро — функція виводу студентів за алфавітом

Функціонал програми
- Додавання нового студента до словника
- Сортування студентів за середнім балом
- Пошук студента за прізвищем, ім'ям та по батькові
- Вивід списку студентів у алфавітному порядку
